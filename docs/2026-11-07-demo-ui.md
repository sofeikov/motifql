# Nov 3 stage — demo UI, `/compile`, rehearsal script

Plan row: DESIGN.md §9, Nov 3. The UI-stack open question (§12) is
resolved from workspace facts: the FastAPI service already existed, so
the UI is one self-contained page (inline SVG + vanilla JS, zero new
dependencies) served by the same app — no CDN reliance, so the
recording cannot break offline.

## 1. What was built

`src/motifql/compile_service.py` — `POST /compile` logic (DESIGN.md
§6.6, §7.1 step 5). Runs `repair_loop` with an injected model
transport (no sanity feedback — RQ4 showed it hurts), then scores
the candidate: pinned `anchor_tids` go exact, otherwise a seeded
sample ranks by top_score. Returns the motif plus ≤3 witnesses with
hops and explanations. Every response labels its source: `model`,
`cache` (all calls prompt-cache hits) or `canned`.

`ui/canned.json` — the committed scripted pair: RQ4 `cycle-basic`,
whose cached reply is a genuine first-round Spark output
(`cached: False` in the record). Verified compiling; scores train
CYCLE instance 102 at top 0.718 with a full-overlap witness.
Current prompts reproduce the exact cache key, so warm machines
serve it from disk and cold ones from this file.

`ui/index.html` + `ui/app.js` — the page. Left rail: English box,
Compile + Scripted-demo buttons, motif code, witness tabs,
per-predicate degree bars with weakest-step notes. Stage: SVG
witness (circular layout for cycles, arc otherwise), hop-by-hop
playback with amount/gap labels, narrating caption, progress
scrubber, step controls, legend. `?at=` deep-links a moment,
`?autoplay=0`/`?autorun=0` hold stills, reduced-motion users get
the final frame. `GET /demo-config` keeps the scripted sentence
and anchor in one place (server side).

`src/motifql/server.py` — `/compile` (CompileError → 502 model /
422 input), `/` + `/app.js`, `/demo-config`, and `--demo` (HI-Small
warmup + rehearsal card; clear error when data is absent).

`src/motifql/graph.py` + `engine.py` — `pos_of(tid)` (O(1) while
ids mirror positions, argsort fallback otherwise; maintained
across appends and rebuilds) and `Engine.score_with` (score one
position against an ad-hoc plan).

`docs/REHEARSAL.md` — boot command, four narrated beats with
timings, fallbacks, recording checklist.
